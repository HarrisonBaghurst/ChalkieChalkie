<h1 align="center">Chalkie Chalkie</h1>
<p align="center"><b>Where effort becomes understanding</b></p>

Chalkie Chalkie is an online, collaborative workspace built specifically with tutoring in mind. The platform is currently in **Beta**, so if any issues are encountered, please don't hesitate to contact us. This can be done through the bug-report form on the site or by adding directly to the issues in this repository.

## Features

- Real time collaborative canvas
- Lesson and workspace management
- Tutor-student relationships
- Accounts and access control

## Tech stack

- Framework & language - Next.js, React, TypeScript
- Styling & UI - Tailwind CSS, Shadcn/ui
- Real time collaboration - Liveblocks
- Auth & access control - Clerk
- Data & storage - Supabase
- Infrastructure - Upstash Redis, Vercel Cron
- Messaging - Resend

## Future development

- Messaging between students and tutors
- AI LaTeX conversion from workspace notes
- Pre-lesson reminder notifications and RSVP status
- Further visual polish e.g. page transition animations
